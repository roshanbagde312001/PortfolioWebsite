# Roshan Bagde — Portfolio

React + Vite portfolio with Apple-launch-style scroll animations (Framer Motion + Lenis).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview
```

- All content lives in `src/data.js` — edit text, skills, jobs and projects there.
- Résumé download: `public/Roshan_Bagde_Resume.docx` (replace with a PDF and update `profile.resume` if you prefer).
- Deploy `dist/` to Vercel, Netlify or GitHub Pages.
